# Stop Slop

Устраняет предсказуемые признаки ИИ-письма из прозы.

## Основные правила

1. **Режь слова-заполнители.** Убирай вводные «прочистки горла», костыли для усиления и все наречия. См. [references/phrases.md](references/phrases.md).

2. **Ломай шаблонные конструкции.** Избегай бинарных противопоставлений, перечислений через отрицание, драматической фрагментации, риторических заходов, ложной субъектности. См. [references/structures.md](references/structures.md).

3. **Пиши в активном залоге.** В каждом предложении есть человек, который что-то делает. Никакого пассива. Никаких неодушевлённых предметов, выполняющих человеческие действия («жалоба превращается в исправление»).

4. **Будь конкретен.** Никаких размытых деклараций («Причины структурны»). Назови конкретную вещь. Никаких ленивых крайностей («все», «всегда», «никогда»), выполняющих туманную работу.

5. **Помести читателя в комнату.** Никакого голоса рассказчика издалека. «Ты» лучше, чем «Люди». Конкретика лучше абстракций.

6. **Меняй ритм.** Чередуй длину предложений. Два пункта лучше трёх. Заканчивай абзацы по-разному. Никаких длинных тире как драматической паузы.

7. **Доверяй читателю.** Излагай факты прямо. Пропускай смягчения, оправдания, разжёвывание.

8. **Режь «цитатки».** Если фраза звучит как вынос в эпиграф — перепиши её.

## Быстрые проверки

Перед сдачей текста:

- Есть наречия? Убей их.
- Есть пассивный залог? Найди деятеля, сделай его подлежащим.
- Неодушевлённое делает человеческое действие («решение возникает»)? Назови человека.
- Предложение-вопрос вместо утверждения? Перестрой.
- Есть «вот в чём дело / вот что» — прочистка горла? Сразу к сути.
- Есть противопоставления «не X, а Y»? Скажи Y напрямую.
- Три предложения подряд одной длины? Сломай одно.
- Абзац кончается хлёсткой однострочной фразой? Поменяй.
- Длинное тире для драмы? Убери.
- Размытая декларация («Последствия значительны»)? Назови конкретное последствие.
- Рассказчик издалека («Никто это не задумывал»)? Помести читателя в сцену.
- Мета-связки («Дальше в этом эссе…»)? Удали. Пусть текст движется сам.

## Оценка

Оцени по шкале 1–10 каждое измерение:

| Измерение | Вопрос |
|-----------|--------|
| Прямота | Утверждения или анонсы? |
| Ритм | Разнообразный или метрономный? |
| Доверие | Уважает ум читателя? |
| Естественность | Звучит как человек? |
| Плотность | Есть что выкинуть? |

Меньше 35/50 — переписывай.
