# Stop Slop

Навык для удаления признаков ИИ из прозы.

## Что это

У ИИ-письма есть паттерны. Предсказуемые фразы, конструкции, ритмы. Этот навык учит Claude (или любую LLM) ловить и убирать их.

## Структура навыка

Основные инструкции лежат в `SKILL.md`, справочные материалы — в папке `references/`: фразы для удаления, структурные паттерны, которых стоит избегать, и трансформации «до/после».

```
stop-slop/
├── SKILL.md
├── references/
│   ├── phrases.md
│   ├── structures.md
│   └── examples.md
├── CHANGELOG.md
├── LICENSE
└── README.md
```

## Быстрый старт

- Добавь эту папку как навык в Claude Code.
- Загрузи файлы в knowledge проекта Claude.
- Встрой правила в кастомные инструкции.
- Включи `SKILL.md` в system-промпт через API.

## Что ловит

Навык находит запрещённые фразы (вводные прочистки горла, деловой жаргон, наречия, размытые утверждения), структурные клише (бинарные противопоставления, пассивный залог, фрагментацию) и проблемы уровня предложения (вопросительные заходы, длинные тире, ленивые крайности).

## Оценка

Оценивает прозу по пяти измерениям: прямота, ритм, доверие, естественность, плотность — каждое по шкале 1–10. Меньше 35/50 — нужна переработка.
